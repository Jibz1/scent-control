# iPhone screens

Screenshots of the iPhone app (`apps/ios`) on sample data, in light and dark mode, for
review. The diffusers, IDs and broker in them are made up. To make them again, from
`apps/ios`, build for the simulator and run `sh scripts/screens.sh`, which writes each screen
to `build/screens`; these contact sheets are made from those.

- `main-light.jpg`, `main-dark.jpg`: the diffusers, a diffuser's room and the rest of its
  screen, and a diffuser that's off.
- `sheets-light.jpg`, `sheets-dark.jpg`: the schedule editor, Copy Schedule, Add Diffuser,
  Settings and the activity log.
- `icon.png`: the app icon in its light, dark and tinted versions.
